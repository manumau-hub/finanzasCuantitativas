# UCEMA QUANT

Streamlit. Pricing de opciones, payoffs y estrategias con market data. Solo español.

## Páginas

| Página | Descripción |
|--------|-------------|
| **UCEMA QUANT** | Home + documentación |
| **Propiedades de opciones** | Clase 1–2 · Eje 2 — Sensibilidad Call/Put (BS / BAW) |
| **Payoffs y Estrategias** | Clase 1–2 · Ejes 1 y 3 — Vanilla, estrategias, Payoff Explorer |
| **Market Data** | Clase 1–2 · Eje 4 — Ticker, spot, options chain |
| **Modelos de Pricing** | Comparar BS, binomial, MC, FD, BAW… |
| **Griegas** | Clases 3–4 — Delta, Gamma, Vega, Rho, Theta vs Spot |
| **Market Data Pricing** | Clases 3–4 · Ejes 3 y 4 — Estrategias con precios de mercado |
| **Notebooks** | JupyterLab · `Notebooks/ejes/` |

## Cómo levantar la app

Desde la **raíz del repo**:

```bash
pip install -r webapp/requirements.txt
python -m streamlit run webapp/UCEMA_QUANT.py
```

**Windows:** `webapp\run_webapp.bat`

Abrí [http://localhost:8501](http://localhost:8501)
