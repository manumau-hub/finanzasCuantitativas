finanzasCuantitativas
=====================

Derivados Financieros - QUANt 2026 - UCEMA

Modelos de pricing de opciones (Black-Scholes, binomial, Monte Carlo, diferencias finitas),
payoffs (vanilla, estrategias, digitales, Asian, barrier), volatilidad implícita y utilidades.

Estructura del proyecto
-----------------------

- **Codigo/pricing/** — Modelos de pricing (BS, binomial, MC, FD; nativos y QuantLib)
- **Codigo/analytics/** — Payoffs, volatilidad implícita
- **Codigo/utils/** — Gráficos, utilidades
- **Codigo/calculadoras/** — Interfaces gráficas (Tkinter)
- **Codigo/data/** — Extractores de datos (Byma, Yahoo)
